
Smart Text Helper :-

Provides Option using Popup to Convert Selected Text to Hyperlink,
Clicking on this hyperlink searches the converted text on Google.
(Can be disabled from settings => Addon -> Details -> Options)

Provides Option using popup to Copy Selected City Name in the format "City_Name, Country_Name" or "City_Name, State_Abbreviation" or "City_Name, Region_Abbreviation".
Popup show two options: Copy and Search Converted Text for City Name.

Examples:-
If "Paris" is selected then "Paris, France" can be copied or searched.
If "Chicago" is selected then "Chicago, IL" can be copied or searched.
If "London" is selected then "London, UK" can be copied or searched.

You can add city country name pairs in settings.

More than 1000 cities added.

Toolbar Icon Settings Provides option to select USA and Europe Region, By Default Both are enabled.

If you select "Birmingham" then two options are shown if both regions are enabled:
"Birmingham, AL"
"Birmingham, UK"

Auto-Copy is available in settings which copies converted text without displaying popup.

Remove Hyperlink Option is also present.

Import and Export Settings is available in settings.
